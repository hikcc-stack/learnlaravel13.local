## Инициализация нового проекта Laravel
## Инструкция по модификации файла hosts для обхода региональных ограничений Packagist
>При возникновении сетевых тайм-аутов или блокировок со сторны CDN ри выполнении команд ```composer create-project``` 
> или ```composer install``` необходимо перенаправить трафик на валидные IP-адреса репозиториев в обход локальных
> DNS-серверов.
1. Откройте конфигурационный файл по пути: ```C:\Windows\System32\drivers\etc\hosts```
2. Вставьте подготовленный блок записей в конец файла
```text
138.199.37.232 packagist.org
138.199.37.232 repo.packagist.org
```
Либо зайдите в настройки OSPanel, перейдите во вкладку "Файл HOSTS" добавьте блок записей в конец файла

### 1. Актуализация пакетного менеджера
Обновление локального исполняемого файла Composer до последней стабильной версии
``` bash
composer self-update
```
### 2. Инициализация каркаса приложения
Развертыванеи чистого скелета Laravel в текущюю рабочую директорию, в которой мф находимся:
```bash
composer create-project laravel/laravel .
```
Развертывание чистого скелета Laravel и создание рабочей директории:
```bash
composer create-project laravel/laravel learnlaravel13.local
```
после чего необходимо перейти в директорию с проектом(если вы еще не находитесь в ней)
```bash
cd learnlaravel13.local
```
### 3. Кофигурация API-слоя
Инсталяция и автоматическая настройка пакета аутентификации (Laravel Sanctum), а также генерация базовых маршрутов для работы в режиме Stateless API:
```bash
php artisan install:api
```
### 4. Экспорт конфигурации CORS
Публикация конфигурационного файла config/cors.php для управлениям политиками кросс-доменных запросов
(Cross-Origin):
```bash
php artisan config:publish cors
```
### 5. Инициализация символьной ссылки для Storage
Создание симлинка из публичной директории public/storage в изолированное хранилище storage/app/public для обеспечения контролируемого HTTP-доступа к медиафайлам
```bash
php artisan storage:link
```
### 5. Маршрутизация веб-сервера(Apache)
оздание или перезапись файла конфиграции .htaccess в корневой директории для перенаправления входящего трафика на фронт-контроллер public/index.php
```apache
RewriteEngine On
# Перенаправление всех входящих HTTP-апросов в публичную директорию public/
Rewrite ^(.*)$ public/$1 [L]
```

## Развертывание существующего проекта из репозитория

### 1. Клонирование и инициализация зависимостей 
Загрузка исходного кода из удаленного репозитория и установка backend-зависимостей согласно ```composer.lock```:
```bash
git clone https://github.com/hikcc789/learnlaravel13.git .
cd learnlaravel13
composer install
```

### 2. Подготовка окружения и генерации app_key(ключа приложения)
```bash
cp .env.example .env
php artisan key: generate
```
### 3. Миграция и сидирование базы данных
Выполнение базовых DDL-скриптов для построения структуры таблиц с параллельным наполнением справочников тестовыми или системными данными (Seeders)
```bash
php artisan migrate --seed
```

## Конфигурация подключения к СУБД(.env)

Параметры интеграции с базой данных MySQL(версии 8.4+) и глобальные настройки сессий в файлы .env:
```env
# Параметры подключения к СУБД
DB_CONNECTION=mysql
DB_HOST=MySQL-8.4
DB_PORT=3306
DB_DATABASE=learnlaravel13
DB_USERNAME=root
DB_PASSWORD=
# Драйвер сессий(локальное файловое хранилище)
SESSION_DRIVER=file
```
